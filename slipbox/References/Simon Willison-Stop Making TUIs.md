# Stop Making TUIs

**Fonte:** Simon Willison (link para Thomas Ptacek / sockpuppet.org)
**Data:** 21 de agosto de 2026
**URL original:** https://simonwillison.net/2026/Aug/21/stop-making-tuis/ (aponta para https://sockpuppet.org/blog/2026/08/20/stop-making-tuis/)

## Resumo

Thomas Ptacek defende construir interfaces nativas de verdade até para as menores ferramentas pessoais, porque coding agents derrubaram o custo de montar um GUI "usável o suficiente" a quase zero. Simon endossa: continua usando diariamente os apps de monitoramento de banda/GPU que vibe-codou em SwiftUI em março.

## Notas principais

- A justificativa histórica dos TUIs para tools pessoais (GUI custa caro para construir) evaporou com agents.
- Ptacek: "Se você não tentou transformar um dos seus 500 CLIs descartáveis num app nativo, está se privando. Vai construir uma UI nativa. Provavelmente vai mudar sua forma de pensar."
- Evidência do Simon: apps vibe-coded na task bar do macOS (bandwidth + GPU) em uso diário desde março.
- Simon admite: ainda não faz UIs reais para todos os projetos por hábito — "estou ficando sem desculpas".
