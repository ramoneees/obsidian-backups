# My obituary for programming

**Fonte:** Simon Willison | **Data:** 2026-10-19 | **URL:** https://simonwillison.net/2026/Oct/19/my-obituary-for-programming/

## Resumo

Link para o "obituário" da programação de Jeremy Scheff: captura com precisão a perda sentida por programadores de carreira que gostavam do quebra-cabeça de desenvolver código — profissão que pagava cada vez melhor quanto mais complicado o puzzle.

## Ideias principais

- A perda central não é empregabilidade, é o prazer do puzzle que definiu a profissão
- Piega: até puzzles simples valiam muito dinheiro porque "pessoas normais" não conseguia fazer
