# Browse tools.simonwillison.net by tag

**Fonte:** Simon Willison (Simon Willison, Tools) | **Data:** 2026-11-11 | **URL:** https://simonwillison.net/2026/Nov/11/tools-tags/

## Resumo

O catálogo de ferramentas vibe-coded do Willison (tools.simonwillison.net) ganhou tag clouds para navegar a coleção — 244 ferramentas e contando — por três eixos novos: APIs JavaScript, bibliotecas e hosts de web APIs usados por cada tool.

## Ideias principais

- Como chegou lá: sobraram créditos semanais do Fable 5.2, e ele colocou o modelo para analisar o código de cada ferramenta com tree-sitter, extraindo as categorias de tag automaticamente.
- O problema é novo na prática: coleções grandes de artefatos gerados por IA precisam de metadados derivados do próprio código (não de tags manuais) para continuarem navegáveis.
- Uso interessante de crédito que ia expirar: trabalho de manutenção/meta que ninguém priorizaria virou feature em uma sessão.
