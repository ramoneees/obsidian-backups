# llm-openrouter 0.7

**Fonte:** Simon Willison (beat)
**Data:** 21 de agosto de 2026
**URL original:** https://simonwillison.net/2026/Aug/21/llm-openrouter/

## Resumo

Release do plugin `llm-openrouter` 0.7: agora compatível com **LLM 0.32**, o que permite exibir os **reasoning traces** dos modelos disponíveis via OpenRouter.

## Notas principais

- Compatibilidade com LLM 0.32 (reasoning traces visíveis).
- Modelos passaram a usar a implementação da **Responses API** do OpenRouter.
- Três novas server-side tools: **Shell**, **WebFetch** e **WebSearch** — habilitar com `-T WebSearch` etc.
- Release notes: https://github.com/simonw/llm-openrouter/releases/tag/0.7
