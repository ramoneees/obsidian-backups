# Introducing Kimi K3.1 Pro

**Fonte:** Simon Willison | **Data:** 2026-10-23 | **URL:** https://simonwillison.net/2026/Oct/23/kimi-k31-pro/

## Resumo

Kimi K3.1 Pro chegou à API da Moonshot — ainda sem open weights, mas com promessa de liberar os pesos completos até 4/nov/2026; versão Highspeed 2-3x mais rápida pelo dobro do preço.

## Ideias principais

- Preço em dólar: $2/M tokens de input, $10/M de output (mesma faixa do modelo não-Highspeed)
- Cache hits de input têm preço igual nas duas versões
- Padrão Moonshot: API primeiro, pesos abertos depois
