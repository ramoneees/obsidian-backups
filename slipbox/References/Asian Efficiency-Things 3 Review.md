# Things 3 Review

**Source:** Asian Efficiency (Thanh Pham)
**Date:** 2026-07-14
**URL:** https://www.asianefficiency.com/task-management/things-3-review/

## TL;DR

Things 3 is worth the $80 one-time price **if you're all-in on Apple, work solo, and want to own your task manager instead of renting it**. Over five years it costs **73% less than Todoist** ($80 vs $300). The tradeoffs: **no AI, no web app, no collaboration, no integrations beyond Apple Shortcuts**.

## Things 3 at a glance

| Question | Answer |
|---|---|
| Price | $80 total, one-time (iPhone $9.99, iPad $19.99, Mac $49.99) |
| AI features | None — Apple's system Writing Tools only |
| Platforms | Mac, iPhone, iPad, Apple Watch, Vision Pro (no web, no Android, no Windows) |
| Collaboration | None — solo tool only |
| Best for | Apple-only solo users who value design and want to own the app |
| Skip it if | You want AI, a web app, team features, or deep integrations |

## What makes Things different

1. **Apple-native everything.** Not a web app with an iOS wrapper. Native animations, typography, iPhone haptics, Mac keyboard shortcuts. iCloud sync is fast, end-to-end encrypted, free.
2. **The hierarchy makes sense.** Areas → Projects → Tasks → Headings. One level deeper than most need, one shallower than OmniFocus. Exactly right for most solo professionals.
3. **No subscription.** $80 once across iPhone + iPad + Mac. Updates are free. The app bought in 2020 still works, still updates, still costs the same.
4. **Speed.** Opens instantly. Quick Entry under a second from any app. No loading states. After subscription apps, Things feels like cheating.

## What Things does well

**Today View.** Tasks scheduled for today + tasks due today. Nothing else. No inbox noise, no overdue items from last November. You trust the app because it doesn't lie about what's on your plate.

**Natural-language date parsing.** "Review contract Thursday." "Follow up next Monday at 9am." "Every two weeks starting April 1." Covers everyday scheduling.

**Quick Entry on Mac.** Ctrl+Space (or custom) opens floating entry over any app. Title → date → project → Enter. ~5 seconds. Best quick-capture on Mac.

**Someday List.** "Learn Portuguese." "Read Anna Karenina." "Research standing desk options." Parked, reviewed occasionally. The trust-builder: things won't disappear, but won't show up when you don't want them.

**Archiving Projects.** Right-click → Archive. Finished projects disappear from sidebar but stay searchable. Areas stay clean over time.

## What Things lacks (honesty)

- **No AI.** Period.
- **No collaboration.** Solo only.
- **No web app.** iCloud sync via Mac/iOS only.
- **No rich integrations** beyond Apple Shortcuts.
- **No recurring task templates** beyond simple patterns.
- **No advanced GTD features** like contexts or location-based reminders.

For a team, an Android user, an AI-heavy workflow, or a Windows environment — Todoist still wins.
