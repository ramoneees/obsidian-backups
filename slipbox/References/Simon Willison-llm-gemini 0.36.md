# llm-gemini 0.36

**Fonte:** Simon Willison (Simon Willison, Release) | **Data:** 2026-11-10 | **URL:** https://simonwillison.net/2026/Nov/10/llm-gemini/

## Resumo

Release 0.36 do plugin Gemini para o LLM: o Gemini 4 Carbon — anunciado duas semanas antes só para "a subset of cyber defenders" — abre para todo mundo. Na avaliação do Willison, é o melhor Gemini já lançado: US$ 2/M de input e US$ 10/M de output no lançamento (nível de GPT-6.1 Sol / Claude Sonnet 5.5), com o preço programado para dobrar para US$ 4/US$ 20 em 1º de dezembro (nível Opus 5.5).

## Ideias principais

- Janela de preço: Carbon custa metade da tabela a partir de 1/dez — período de lançamento é a hora de rodar cargas pesadas no modelo.
- Teste padrão do blog (três pelicans em low/medium/high thinking effort; default é medium) continua entregando qualidade alta — "Gemini pelicans have all been great for a while now".
- Teste comparativo no Google Antigravity IDE com o mesmo prompt do teste de [[Simon Willison-Yonkers Rises]] (Fable 5.2 no dia anterior): animação Three.js do Yonkers como mech, com dados do OpenStreetMap — precisou de um nudge ("build that into a standalone HTML file") para ficar sem dependências externas.
- O destaque real veio do /swarm do Antigravity: Carbon coordenando subagents para modelar assets 3D no Blender, construir o jogo em Three.js/WebGL e parear áudio procedural com música do Lyria — um jogo 3D open-world explorável do campus de Mountain View, jogável no AI Studio, repercutido pelo próprio Pichai.
