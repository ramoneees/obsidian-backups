# Start With the Work That Actually Annoys You

**Fonte:** Asian Efficiency | **Data:** 2026-10-25 | **URL:** https://www.asianefficiency.com/technology/start-with-annoying-work/

## Resumo

O "aha" de IA não veio quando a ferramenta escreveu um e-mail (escrever já era fácil) — veio ao transformar uma pilha de dados não estruturados num CSV importável: o valor aparece quando a IA remove o trabalho que você detesta.

## Ideias principais

- Filtro RATs: procurar trabalho Repetitivo, Annoying ou Time-consuming antes de escolher ferramenta
- Padrão do autor: prompts repetidos → workflow reutilizável
- Se você usa IA só para escrever e-mails melhores, provavelmente está aplicando no trabalho errado
