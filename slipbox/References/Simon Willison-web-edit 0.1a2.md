# web-edit 0.1a2

**Fonte:** Simon Willison | **Data:** 2026-10-17 | **URL:** https://simonwillison.net/2026/Oct/17/web-edit/

## Resumo

Release 0.1a2 do web-edit, o web app do Willison para navegar e editar ficheiros de uma pasta — construído para editar ficheiros em outras máquinas via Tailscale.

## Ideias principais

- Novo: "copy to clipboard" para texto e imagem
- Motivação: rodar prompts do pelican num laptop a partir do celular e copiar o resultado
