# Why Your Goals Are Failing

## Resumo

Metas são destinos; sistemas são o veículo. O TPS dura 11+ anos não por motivação, mas por calendário de conteúdo, cadência definida, workflow e equipe — o show acontece "quase automaticamente", inclusive nas semanas sem inspiração. Motivação é sentimento (infiável); sistema é estrutura ( confiável).

## Ideias principais

- **A pergunta certa não é "como me motivar?" mas "qual sistema falta?"** — Se começar exige uma decisão, você pula quando está cansado. Se já está no calendário, a decisão desaparece: você só aparece.
- **Audit the vehicle** — Para cada meta, escreva numa linha o destino e na outra o processo. Se não consegue nomear o sistema, esse é o gap. "Vou ver isso depois" não é veículo, é destino + humor.
- **Never Skip Twice** — Perder um treino/hábito é vida; perder o segundo é o hábito desmoronando. A regra protege contra o perfeccionismo sem precisar de discurso de comeback.
- **Cultivar o jardim (relacionamentos como sistema)** — CRM pessoal para a rede ampla; tarefa recorrente para os mais próximos (ex.: "The Sunday Call" para ligar aos pais). O sistema carrega o lembrar; você foca na conexão.
- **Sistemas não precisam ser complexos, precisam ser consistentes** — Um bloco de calendário + um template pode ser tudo que o projeto precisa.

## Aplicação prática

- Auditar as metas atuais: nomear o sistema de cada uma (papel, não na cabeça).
- Escolher UMA meta travada e instalar o sistema que falta esta semana (bloco, template, tarefa recorrente, regra Never Skip Twice).
