# webframe: evaluated as a scraper and a sandbox

**Fonte:** Simon Willison | **Data:** 2026-10-26 | **URL:** https://simonwillison.net/2026/Oct/26/webframe-evaluation/

## Resumo

Avaliação do webframe (projeto de Jeff Lindsay): runner de JavaScript de browser, rápido e leve, adequado a scraping — com performance comparável ao shot-scraper, mas com arestas importantes.

## Ideias principais

- Rough edges encontrados: falhas de CSP, viewport 0×0, loads que penduram, metadados HTTP ausentes, controles de browser limitados
- Categoria: pesquisa/avaliação de ferramenta de scraping headless
