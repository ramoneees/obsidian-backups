O diagnóstico do Thanh Pham: uma tarefa chega, você sabe fazer, e faz — sem pausa, sem pergunta. O default é caro não porque cada item é grande, mas porque você nunca avalia se aquilo deveria ser seu. O problema real é lembrar de delegar; a solução proposta é uma tarefa recorrente a cada 2-3 dias com uma linha: "O que posso delegar?". Quando ela dispara, olha o prato e decide na hora: tira de propósito ou mantém de propósito.

O texto traz três ferramentas concretas. Primeira: o Time Squander Audit — liste as microtarefas manuais recorrentes (pagar boleto, caçar anexo, planilha de agenda) e mate a pior delas com uma automação por semana. O objetivo é energia mental, não tempo; tempo volta como efeito colateral. Segunda: os três níveis de delegação de Brooks — fácil (odeio/soço), médio (sei fazer mas não gosto), difícil (sou BOM nisso e ainda assim me drena). A maioria para no nível 1; a alavancagem de verdade está no 3, e "ser bom nisso" não é razão para manter a tarefa. Terceira: a regra dos $200 — um orçamento fixo mensal para comprar tempo de volta, em vez de planilha de ROI para tarefa doméstica.

A progressão recomendada: comece com serviços de tarefa avulsa (Fancy Hands) para sentir o gosto do benefício, depois graduue para um EA dedicado de 5-8h/semana — part-time, não salário no dia um. O primeiro week simples: triagem de inbox e calendar blocking. E a métrica final não é relógio: é energia. Acompanhe como se sente antes e depois de entregar uma tarefa recorrente; a atenção recuperada é o que abre espaço para trabalho criativo de qualidade — ou para estar presente com a família.

Bônus curioso: o "walk-in hack" — quando restaurante aparece lotado online, ligar e pedir (com linguagem de cliente) recupera capacidade escondida que interface digital não mostra.

## Por que importa

- O nível 3 do Brooks é o teu caso exato: você é bom em code review e QA, e mesmo assim o padrão já é delegar todo o coding ao OpenCode. A pergunta recorrente "o que posso delegar?" é o que formaliza o instinto — e vale tanto para APIs quanto para a agenda.
- O Parallel Time Squander Audit é basicamente teu princípio (só automatiza quando os dados já existem) aplicado a tarefas: pequenas coisas manuais recorrentes são as candidatas óbvias para o dispatcher/gateway.
- A métrica de energia e não de tempo casa com a gestão de ADS e com o modus operandi de casa: carinho no gasto, 5-8 categorias, comprar tempo de volta dentro de orçamento ($200/mês é um número testável).
