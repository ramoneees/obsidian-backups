# Quoting Ben Affleck

**Fonte:** Simon Willison
**Data:** 7 de outubro de 2026
**URL:** https://simonwillison.net/2026/Oct/7/ben-affleck/

## Resumo

Citação coletada por Simon Willison. Ben Affleck descreve, com precisão técnica, como o workflow de efeitos visuais usa ML há anos: tensores como tradução numérica da imagem (nº do batch, do frame, valores RGB por pixel), CNNs para detecção de padrões (edge detection, feature extraction) — "é aqui que está a janela, então dá para tirar a imagem da green screen e substituir". E a linha de assinatura: ele escreve "pretty shitty Python scripts" porque o transformer é "muito mais computação simultânea" do que as redes convolucionais que o precederam.

## Por que importa

- Willison enquadra Affleck como "Pythonista": diretor-ator fluente na pilha técnica real de VFX — não é anedota de celebridade, é literacia de base numérica falada naturalmente por um cineasta.
- Bom lembrete de que CNN (feature extraction por convolução) e transformer (atenção sobre tudo contra tudo) resolvem o problema de forma diferente — e que gente de fora da engenharia consegue articular a diferença quando o domínio é dela.
- Para o vault de IA: exemplo didático pronto da cadeia imagem → tensor → convolução → pattern.

## Frase notável

> "So I can write like pretty shitty Python scripts and stuff like that because with convolutional neural networks... which is just identifying patterns enough to know like this is where the window ledge is, so we can more easily take the green screen image out and replace it with something." — Ben Affleck
