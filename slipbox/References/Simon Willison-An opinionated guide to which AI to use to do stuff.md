# An opinionated guide to which AI to use to do stuff

**Fonte:** Simon Willison’s Weblog  
**Data:** 2026-07-27  
**URL original:** https://simonwillison.net/2026/Jul/27/an-opinionated-guide-to-which-ai-to-use-to-do-stuff/

## Resumo / notes principais

Simon comenta a atualização do guia de Ethan Mollick sobre qual IA usar. O foco mudou de chat tradicional — ChatGPT, Claude e Gemini — para sistemas agentivos capazes de executar o equivalente a muitas horas de trabalho humano.

O texto destaca a confusão de nomes: ChatGPT usa Work e Codex; Claude usa Cowork e Code. Os nomes não correspondem entre plataformas. Também chama atenção para a diferença entre ChatGPT Work no celular e no desktop: no celular, o modo Work dá ao contêiner de Code Interpreter acesso à internet, enquanto o aplicativo desktop se aproxima de uma camada mais acessível sobre o Codex.

## Notas e conexões

- A unidade de comparação deixou de ser “qual chatbot responde melhor?” e passou a ser “qual agente executa melhor esta classe de tarefa?”.
- Nomes de produtos e modos continuam deliberadamente pouco intuitivos. Uma tradição tecnológica respeitável.
- Acesso ao computador e à internet é a mudança de capacidade mais relevante.
