# LaTeX renderer

**Fonte:** Simon Willison | **Data:** 2026-10-15 | **URL:** https://simonwillison.net/2026/Oct/15/latex/

## Resumo

Ferramenta: LaTeX renderer — transforma fonte LaTeX em visão renderizada (equação via MathJax ou documento/prosa via faster-latex), com preview ao vivo ao lado do editor.

## Ideias principais

- Fonte pode ser digitada, carregada de URL ou GitHub Gist, ou de exemplos embutidos
- O LaTeX fica no URL fragment — o link compartilhado já é o documento legível
