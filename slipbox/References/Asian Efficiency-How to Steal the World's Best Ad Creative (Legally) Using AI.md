# How to Steal the World's Best Ad Creative (Legally) Using AI

**Fonte:** Asian Efficiency (Thanh Pham)
**Data:** 21 de agosto de 2026
**URL original:** https://www.asianefficiency.com/technology/steal-best-ad-creative-ai/

## Resumo

**Reverse prompting:** em vez de descrever do zero, cola-se um anúncio de referência (ex.: Louis Vuitton) num AI com visão e pede-se o reverse-engineering em prompt detalhado — composição, luz, lente, color grading. Troca-se um noun (o produto) e gera-se imagem no mesmo estilo. "Os melhores anúncios do mundo são basicamente uma prompt library gratuita."

## Notas principais

- O que faz uma foto parecer cara não é orçamento — são decisões de composição **extraíveis**: tipo de shot, luz, ângulo, negative space, mood.
- **Camera language**: prompts com linguagem de fotografia ("85mm, soft directional key light upper-left, slight underexposure, shallow DoF") superam prompts genéricos de marketing.
- Processo: (1) referência → (2) visão AI → (3) prompt JSON → (4) trocar 1 elemento → (5) gerar.
- Poder real está na **prompt library** sistemática: 5-6 estilos reverse-engineered, reutilizáveis com qualquer produto — consistência de marca sem photoshoot.
- Aplicável além de produtos: interiores, espaços, qualquer visual editorial.
