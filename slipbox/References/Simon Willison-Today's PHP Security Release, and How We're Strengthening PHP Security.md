# Today's PHP Security Release, and How We're Strengthening PHP Security

**Fonte:** Simon Willison | **Data:** 2026-10-21 | **URL:** https://simonwillison.net/2026/Oct/21/php-security-release/

## Resumo

Release de segurança do PHP: atualizações em toda a linha 8.x fecham duas falhas de RCE, com exploits circulando desde a véspera por um leak no processo de coordinated disclosure — quem roda PHP precisa atualizar já.

## Ideias principais

- Duas falhas de remote code execution em toda a linha 8.x
- Exploits públicos por leak da disclosure; post da PHP Foundation detalha o fortalecimento do processo de segurança
