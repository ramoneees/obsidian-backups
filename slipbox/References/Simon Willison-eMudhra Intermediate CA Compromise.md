# eMudhra Intermediate CA Compromise

**Fonte:** Simon Willison | **Data:** 2026-10-20 | **URL:** https://simonwillison.net/2026/Oct/20/emudhra-certificates/

## Resumo

Comprometimento de CA: as chaves privadas de oito certificados intermediários da eMudhra foram comprometidas — encadeando para raízes confiadas por Mozilla, Microsoft, Apple e Chrome.

## Ideias principais

- Qualquer software que embute trust store precisa ser atualizado; repo no GitHub rastreia os updates
- Classe de incidente rara e grave: CA intermediária, não site final
