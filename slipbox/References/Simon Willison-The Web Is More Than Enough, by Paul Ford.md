# The Web Is More Than Enough, by Paul Ford

**Fonte:** Simon Willison | **Data:** 2026-11-09 | **URL:** https://simonwillison.net/2026/Nov/9/hn-50421091/

## Resumo

Comentário do Willison no thread do Hacker News sobre o texto de Paul Ford "The Web Is More Than Enough", testado na prática: ele construiu de manhã um ovo de Fabergé temático de nudibranch em Three.js e pediu ao Claude Opus 5.5 (no chat normal) para portá-lo para Vanilla JS puro, na mesma thread. O port funcionou: modelagem 3D com WebGL sem Three.js é perfeitamente viável com o modelo atual.

## Ideias principais

- Os dois builds não ficaram idênticos — e o próprio Willison diz não entender por quê; o transcript compartilhado do Claude documenta as diferenças
- Na leitura do código, o Three.js ainda parece mais fácil de entender, mas ele raramente revisita o código desses projetos 3D, então não pesa
- Corrobora a tese de Ford: a plataforma aberta (web + vanilla JS + LLM no browser) já basta para o resultado
