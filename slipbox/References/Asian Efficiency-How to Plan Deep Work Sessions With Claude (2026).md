# How to Plan Deep Work Sessions With Claude (2026)

**Source**: Asian Efficiency (Thanh Pham)
**Date**: 2026-07-21
**URL**: https://www.asianefficiency.com/productivity/claude-deep-work-planning/

## TL;DR

Spend 5 minutes before every deep work block running a structured planning conversation with Claude: brain-dump everything competing for time, let Claude pick one primary focus, then break that focus into timed steps with clear "done" criteria. Claude beats ChatGPT for this specifically because it pushes back on overambitious scope instead of cheerfully planning the impossible.

## Key Points

- **Why pre-block planning matters**: Without a plan, even protected 3-hour blocks dissolve into email-checking, context-switching, and lunch-with-zero-output. Walking into a block with a checklist removes decision paralysis.
- **The 5-minute pre-block prompt sequence**:
  1. **Brain dump**: "Here are the {3-hour} deep work block starting at {8am}. Here's everything competing for that time..." — dump all projects, tasks, ideas, deadlines, stressors.
  2. **Prioritization**: Claude recommends one primary deliverable based on deadlines, dependencies, energy. Push back if needed; usually 2–3 exchanges.
  3. **Breakdown**: "Break this into specific steps. For each: what I'm producing, how long it should take, what 'done' looks like."
- **Output example**:
  - Step 1 (45 min): Draft workshop outline. Done = 8–10 topics with descriptions.
  - Step 2 (60 min): Write first three sections in detail. Done = 1,500 words of content.
  - Step 3 (45 min): Create participant worksheet. Done = PDF-ready document.
  - Buffer (30 min): Review everything.
- **Weekly deep work map**: Sunday during weekly review, give Claude your priorities + your available deep work blocks. Ask it to map priorities to specific blocks (which need morning energy, which depend on others, which days have meeting-heavy afternoons). Have it flag priorities that won't fit.
- **Rules that stick**:
  - One primary focus per block (never two ambitious deliverables)
  - Hold 20% of the time as buffer
  - Protect the first block of the day
  - Accept that some blocks will break

## Por que isso me interessa

This is the canonical AE answer to "I have time blocked but I'm still not producing." The combination of pre-block planning + Claude's natural pushback fits Ramon's existing stack (Claude Pro, time-blocked calendar) and addresses the chronic complaint that blocks dissolve into email-checking.
