# Before You Automate It, Run the Workflow by Hand

**Fonte:** Asian Efficiency (Thanh Pham)
**Data:** 16 de agosto de 2026
**URL original:** https://www.asianefficiency.com/productivity/run-the-workflow-by-hand/

## Resumo

Tarefa que irrita uma vez é aleatoriedade; que irrita três vezes está pedindo um sistema — mas não uma automação imediata. Com IA o risco é maior: ela produz volume rápido, e se o brief é confuso, produz uma bagunça nova para você limpar. O método: rode o workflow manualmente com IA ao lado antes de automatizar.

## Notas principais

- **Comece pela repetição irritante:** caso do founder com transcripts de reunião — em vez de construir tudo, primeira passada lenta: transcript num chat de IA, inspecionar resultado, ajustar instruções, repetir com outra reunião. A execução manual revela diferenças invisíveis no canvas em branco (uma reunião tem introdução prometida, outra decisão sem owner, outra detalhe que pertence ao CRM e não às notas). Automatizar antes disso é desenhar para uma versão imaginária do trabalho.
- **Escreva o que "done" significa:** ex. para follow-up pós-reunião: email nomeia as decisões; lista toda ação prometida com owner; datas só se a conversa teve datas; incertezas marcadas para review. "Definir a linha de chegada é a parte mais valiosa da delegação para IA."
- **Deixe a IA pedir o contexto que falta:** em vez de caçar o prompt perfeito — "O que você precisa de mim antes de começar?" As respostas viram um pequeno manual de operação da tarefa.
- **Documente o julgamento antes da automação:** regras simples do tipo "inclua decisões e compromissos; não invente deadlines; mantenha o email curto; sinalize o sensível para mim". Teste: se você não consegue explicar como uma pessoa habilidosa decide se o output é bom, a tarefa não está pronta para rodar sozinha.
- **Mantenha a passada humana:** automação é ótima no primeiro rascunho, ruim em saber quando uma frase soa off. Draft-first + review. "A revisão não é busywork — protege confiança."
