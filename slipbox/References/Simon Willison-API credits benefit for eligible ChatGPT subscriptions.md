# API credits benefit for eligible ChatGPT subscriptions

**Fonte:** Simon Willison | **Data:** 2026-10-29 | **URL:** https://simonwillison.net/2026/Oct/29/api-credits/

## Resumo

OpenAI lança praticamente o mesmo benefício que a Anthropic anunciou no início do mês: assinaturas de $100, $200 ou $500/mês passam a incluir aquela mesma quantidade de créditos (expiráveis) para aplicar em uma organização da API. A Anthropic tinha aberto o movimento para Max e Team; a OpenAI copiou em escala.

Simon mantém assinaturas das duas empresas e comemora: com os créditos já cobertos pelas assinaturas existentes, a barreira para publicar demos públicas caiu.

## Ideias principais

- Convergência de pricing entre os dois maiores labs: o consumer subscription virou canal de distribuição de créditos de API — quem assina chat ganha capacidade de desenvolvimento
- Créditos expiráveis (use-it-or-lose-it) como mecanismo: gera engajamento mensal com a API sem dar desconto permanente
- Para devs que já pagam assinatura premium, o custo marginal de experimentar a API (demos, agentes, protótipos) caiu a zero
