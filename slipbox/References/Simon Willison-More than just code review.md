# More than just code review

**Fonte:** Simon Willison (note)
**Data:** 22 de agosto de 2026
**URL original:** https://simonwillison.net/2026/Aug/22/more-than-just-code-review/

## Resumo

A habilidade-chave para usar coding agents com produtividade é instruir com confiança e **verificar com confiança** que as mudanças foram aplicadas corretamente — e revisar cada linha de código é só uma das formas de chegar lá, não a única nem a mais eficaz.

## Notas principais

- "A habilidade-chave para uso produtivo de coding agents é conseguir instruí-los com confiança sobre como fazer mudanças e depois verificar com confiança que essas mudanças foram aplicadas da forma correta."
- Olhar linha por linha **nunca foi** a forma mais eficaz de validar uma mudança de software — vale para código escrito por humano quanto por agente.
- Verificação ≠ leitura exaustiva: testes, execução, evidências comportamentais contam.
