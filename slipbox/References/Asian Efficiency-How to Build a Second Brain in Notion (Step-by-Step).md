# How to Build a Second Brain in Notion (Step-by-Step)

## The Rule of Four

A Notion second brain needs **four databases**. Not three, not seven. Four.

| Database | Purpose |
| --- | --- |
| **Inbox** | Catch ideas, links, notes, voice memos before they disappear |
| **Projects** | Active work with a clear end point |
| **Areas** | Ongoing responsibilities (5–8 max) |
| **Resources** | Reusable reference material |

Plus one **dashboard** page linking views of all four.

## Setup Steps

### Step 1: Four Core Databases (15 min)

- **Inbox**: Title, Type (idea/article/meeting/task/reference), Date Added (auto)
- **Projects**: Title, Status (active/on hold/completed/archived), Area, Target Date
- **Areas**: Title, Description (one line). Limit to 5–8. Mine: AI Consulting, Asian Efficiency, Health, Finance, Relationships, Events, Learning.
- **Resources**: Title, Type (book/article/template/reference/how-to), Area (relation), Tags

### Step 2: Dashboard (10 min)

Linked views of each database on one page. Inbox (unprocessed), Active Projects (board by Area), Areas (list), Recent Resources (last 10). Make this your Notion home page.

### Step 3: Capture Flow (5 min)

The 5-second rule: **if capture takes more than 5 seconds, you won't do it consistently.**

- Phone: Notion Quick Add widget
- Computer: Notion Web Clipper → Resources
- Email: Forward to Notion email-to-page address

### Step 4: Weekly Inbox Processing

Schedule 15 min every Sunday. For each item: actionable → Project / reference → Resources / irrelevant → delete / connected → link to Area.

### Step 5: Notion AI (5 min, Business plan)

- AI Search (natural language over your notes)
- AI Summaries (long article → summary)
- AI Writing (draft from captured context)
- AI Agents (custom, 2026)

### Step 6: Context Files (optional, powerful)

Folder of pages: **Who I am**, **How I work**, **What I'm working on**. AE's context file system powers 40–50 AI agents that reference this constantly.

## Common Mistakes

- **Over-engineering from day one** — build as you need it, not before
- **Too many Areas** — 20 areas = zero areas. Keep to 5–8.
- **Never processing Inbox** — capture without processing is just organized hoarding
- **Treating second brain as a library** — store what you actually use, delete the rest
- **Spending more time on the system than on the work** — if maintenance is >1h/week, something is wrong

## Pro Tips

- Use relations between databases (Projects↔Areas, Resources↔Areas, Inbox→Projects)
- Add a "Waiting For" status to Projects
- Archive, don't delete (change status to Archived)
- Make dashboard the Notion home page
