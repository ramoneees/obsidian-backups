# The First 250 Books for Your Church Library

**Fonte:** Tim Challies | **Data:** 2026-10-22 | **URL:** https://www.challies.com/articles/the-first-250-books-for-your-church-library/

## Resumo

Lista com os primeiros 250 livros para montar uma boa biblioteca de igreja — fruto das vezes em que Challies foi pedir para avaliar acervos; lista para crianças vem a seguir.

## Ideias principais

- Começa por "Starting Out": livros para novos crentes e quem os discipula
- Honestidade do autor: ninguém vai concordar com tudo — "amanhã eu mesmo provavelmente não concordarei com todos"
- Disponível em formato para download e impressão; links são de afiliado (declarado)
