# Plaud Note Review

## Fonte

- **Source**: Asian Efficiency
- **Author**: Thanh Pham
- **Published**: 2026-07-11 (last updated 2026-07-06)
- **URL**: https://www.asianefficiency.com/technology/plaud-note-review/

## Resumo

Plaud não é só um recorder — é hardware + app + AI transcription layer empacotados, feito para capturar conversas longe do laptop: client meetings, coffee chats, phone calls. **Pick default**: Plaud Note Pro ($189) + Pro subscription ($99.99/ano, ~20 horas/mo). **Pule inteiro** se suas meetings são 90% Zoom (Granola/Otter fazem melhor).

### Lineup

| Device | Preço | Best for |
| --- | --- | --- |
| Plaud Note | $159 | Original, clip-on ou table capture |
| Plaud NotePin | $159 | All-day wearable, lapel ou lanyard |
| Plaud NotePin S | $179 | Upgrade incremental sobre NotePin |
| Plaud Note Pro | $189 | Display, longer battery, melhor mic array |

### As três camadas do Plaud

1. **Hardware** — captura áudio localmente, sem cloud durante gravação.
2. **App** — sync recordings para o telefone via Bluetooth/WiFi, gerencia files.
3. **Plaud Intelligence** — AI layer (GPT-4 class), 112 idiomas com speaker labels. Sem subscription, é só um recorder que armazena audio files.

### Note Pro (novo, top-of-line)

- InstantView AMOLED display (finalmente, dá para ver o que está gravando).
- 4 MEMS + 1 VPU microphones, capta vozes até 16.4 ft.
- 50 horas battery (vs 30 do original).
- Smart dual-mode switching (automatic vs manual no Note).
- Multimodal input: typed notes e images junto com audio.

### Use case interessante

Time do autor testou NotePin para cliente que precisava capturar **toda conversa** (não só meetings scheduled). Pairing com Claude Bot local rodando em Mac Mini: NotePin sincroniza recordings automaticamente → bot transcreve localmente (sem cloud API costs) → flag names/context em Airtable contact database. Dia inteiro, indexado e searchable.

### Tradeoffs honestos

- **Não substitui** Granola/Otter para Zoom meetings — Plaud resolve problema diferente (in-person + phone).
- Audio quality é ambient, não directional lapel mic. Múltiplas pessoas falando ou sala acústica ruim = transcript com gaps.
- Transcription accuracy ~90-95% para native English em condições decentes; pior em restaurante/open office.
- Phone call recording só funciona com port connector físico no iPhone.

## Key Takeaways

1. Plaud é para **captura fora do laptop** — in-person meetings, coffee chats, phone calls. Não compete com Granola/Otter para Zoom.
2. Subscription é necessária para AI features ($99.99/ano); sem ela, é só um recorder caro.
3. Note Pro ($189) é o sweet spot atual; NotePin é interessante para all-day ambient capture.
4. Caso de uso mais forte: knowledge workers que perdem informação entre calls (não no meeting, mas no que vem antes/depois).
