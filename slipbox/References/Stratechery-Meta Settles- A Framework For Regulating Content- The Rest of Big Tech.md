# Meta Settles, A Framework For Regulating Content, The Rest of Big Tech

**Fonte:** Stratechery (Ben Thompson) — Daily Update  
**Data:** 31 de agosto de 2026  
**URL original:** https://stratechery.com/2026/meta-settles-a-framework-for-regulating-content-the-rest-of-big-tech/

## Resumo / notas principais

Tese do artigo (resumo do excerpt público): **"O acordo da Meta faz sentido para todas as partes, mas todo o saga mostra por que qualquer solução para regular tecnologia parece errada."**

- **Meta settles** — o acordo (US$ 18 bi, conforme cobertura da semana) com os procuradores-gerais dos estados. Thompson: racional para todos os envolvidos — Meta limita passivo e incerteza, estados obtêm concessões de design.
- **A framework for regulating content** — o ponto central não é o valor, mas os requisitos de design impostos: o regulador acaba desenhandado plataformas por decreto, o que é problemático para qualquer framework de regulação de conteúdo.
- **The rest of Big Tech** — os mesmos padrões being empurrados para YouTube, Snapchat e TikTok (ainda em litígio).
