# Quoting Daniel Stenberg

**Fonte:** Simon Willison's Weblog (quotation post) | **Data:** 2026-11-18 | **URL:** https://simonwillison.net/2026/Nov/18/daniel-stenberg/ | **Via:** https://daniel.haxx.se/blog/2026/11/17/actual-curl-rewrites-in-rust/

## Resumo / notas principais

Citação de Daniel Stenberg (criador e lead do curl) sobre as reescritas do curl em Rust feitas por agentes de IA:

> "During the time these agents converted 185,000 lines of C code into 340,000 lines of Rust code (I counted), we merged over 300 commits in the actual curl project. We actually improved curl during these a little more than three weeks. A little over 200 bugfixes actually. 200 bugfixes that none of those rust rewrites have. We also fixed a few vulnerabilities. In another month we have done another 200 and maybe fixed a few more vulnerabilities. Will these clones keep up?"

A pergunta final é a tese: enquanto os agentes produziram volume de código (que ninguém mergeou), o projeto real acumulou 200+ bugfixes e fixes de vulnerabilidade em 3 semanas. Volume de código reescrito ≠ progresso de software.
