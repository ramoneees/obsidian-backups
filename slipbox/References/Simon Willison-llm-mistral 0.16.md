# llm-mistral 0.16

**Fonte**: Simon Willison (release)
**Data**: 2026-10-06 . **URL**: https://simonwillison.net/2026/Oct/6/llm-mistral/

> Plugin LLM de acesso aos modelos Mistral via Mistral API — agora com suporte a modelos de raciocínio.

## Resumo

Release de uma linha que adiciona ao plugin `llm-mistral` suporte a modelos de raciocínio, como o recém-lançado Mistral Large 4.

## Ideias principais

- Cadência de manutenção de plugin engatada ao calendário de lançamentos do provedor: modelo novo no ar, plugin atualizado no mesmo dia.
- Mistral Large 4 chega com níveis de raciocínio — o plugin precisa expor essa configuração para o CLI.
