# Quoting Carson Gross

**Fonte:** Simon Willison (quotation post)
**Data:** 8 de outubro de 2026
**URL original:** https://simonwillison.net/2026/Oct/8/carson-gross/

## Resumo

> Computer programming is, fundamentally, about two things: problem-solving using computers and learning to control complexity while solving these problems. I have a hard time imagining a future where knowing how to solve problems with computers and how to control the complexity of those solutions is less valuable than it is today, so I think it will continue to be a viable career even with the advent of AI tools.
> — Carson Gross (criador do HTMX)

## Notas principais

- A defesa da carreira não apela para "IA não consegue X" — aponta para os dois componentes que a IA não elimina: resolver problemas e **controlar a complexidade** das soluções.
- Quanto mais IA gera código, mais escasso (e valioso) fica quem sabe domar complexidade alheia.
- Eco direto da tese "out-of-context problem": o gargalo migra de escrever código para gerenciar o que já foi escrito.
