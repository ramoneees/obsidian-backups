Post curto anunciando a newsletter mensal de outubro, exclusiva para sponsors (US$ 10/mês adianta um mês sobre a versão free). O próprio post lista os tópicos da edição:

- Créditos de API para assinaturas de US$ 100+/mês.
- O que ele está usando agora; releases do seu software.

A newsletter de setembro foi liberada como preview pública do formato.
