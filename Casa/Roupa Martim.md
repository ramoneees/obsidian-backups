## Regras de kit escola (por máxima do dia)

| Máx | Kit |
|---|---|
| ≥22° | bermuda + t-shirt |
| 18–21° | calça + t-shirt |
| 14–17° | calça + corpo/camisola MC + moletom |
| 10–13° | calça + corpo MC + moletom + casaco |
| <10° | camadas todas + gorro |

- Chuva ≥50% → botas + impermeável + meia reserva na mochila
- Calça pode repetir dia sim/dia não → 4 bastam pra semana
- Camadas saem e voltam conforme a tarde esquenta
